Orçamento de hospedagem

Onde o site está publicado, por que escolhemos essa opção e quanto custaria.

Comparação das opções

Plataforma Custo para este site HTTPS Observação
Railway ✅ escolhida Plano Free: US$ 0 (crédito de US$ 1 por mês). Plano Hobby: US$ 5 por mês (inclui US$ 5 de uso) Sim, automático Roda o server.js com o Dockerfile do projeto e publica de novo a cada push no GitHub
GitHub Pages R$ 0 (grátis para repositório público) Sim, automático Ótimo para site estático. Fica como plano B se o Railway sair do ar
Vercel ou Netlify Plano gratuito para projetos pessoais Sim, automático Também serviriam, mas exigem conta e configuração em mais um serviço

Por que escolhemos o Railway

  • Já estava pronto no projeto: o Dockerfile, o server.js e o railway.toml deixam o site rodando do mesmo jeito no computador e na internet.
  • HTTPS automático, como pede o roteiro: sustentabilidadeparatodos.up.railway.app.
  • Ligado ao GitHub: cada push na branch main publica a nova versão.
  • Pensando no futuro: por ter um servidor Node, dá para enviar os formulários por e-mail de verdade, coisa que um site só estático não faz.
